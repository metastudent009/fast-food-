# 🔥 EMBERLY — Fire-Grilled Fast Food

A modern fast food restaurant website built with plain HTML, CSS and JavaScript (no frameworks, no build step).

## Features
- Home, Menu, About, Offers, Locations, Contact, Cart, Checkout and Admin pages
- 9 menu categories (Burgers, Chicken, Shrimp, Pizza, Fries, Snacks, Drinks, Desserts, Combos) with search and filters
- Shopping cart with quantities, coupons, loyalty points, tax and delivery calculation
- Checkout with delivery address form and order confirmation
- Admin dashboard: add / edit / delete products, change prices and images, manage orders, view sales stats, manage coupons
- Reviews, FAQ, newsletter, animated loader, scroll animations, responsive design

## Run locally
Open `index.html` in any browser. No installation needed.

## Structure
```
index.html
css/style.css
js/app.js
images/
```

## Demo coupons
`EMBER10` (10%), `FRIES5` (5%)

## Notes
- Data (cart, orders, products) is stored in the browser's `localStorage`. There is no backend and no real payment.
- Admin panel: `index.html#/admin` (no password, demo only).
